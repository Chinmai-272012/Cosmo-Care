# Deployment checklist

- [ ] Push project files to GitHub (never include `.env` or API secrets).
- [ ] Import the repository into Vercel.
- [ ] Add `ANTHROPIC_API_KEY` in Vercel Environment Variables.
- [ ] Redeploy.
- [ ] Confirm the website loads.
- [ ] Test Nova chat.
- [ ] Save a sample vital reading and test Claude Vitals Review.
- [ ] Check Settings → AI data sharing before entering any personal data.

A Vercel deployment URL is created by Vercel; it cannot be known until the project is deployed.
